# MUSICA Groovebox (app para el teléfono)

Groovebox del proyecto MUSICA (Web Audio): secuenciador en anillo con largo por pista, 2 sintes, acordes, batería con 10 kits, sampler con 4 chops, mixer con envíos y efectos, sirena dub, partes A–D.

## Instalar en el teléfono
1. Abrí el enlace de GitHub Pages de este repositorio.
2. **Android (Chrome):** menú ⋮ → *Instalar app* (o *Agregar a la pantalla principal*).
   **iPhone (Safari):** botón Compartir → *Agregar a pantalla de inicio*.
3. Abrila desde el ícono: queda a pantalla completa y funciona sin internet.

## Acelerómetro (ACEL)
- **Android:** Chrome › Configuración › Configuración de sitios › Sensores de movimiento → Permitir.
- **iPhone:** al tocar ACEL elegí *Permitir*.

## Actualizar
Subí el `index.html` nuevo y cambiá el nombre del caché en `sw.js` (`musica-gb-vX.Y`). La app toma la versión nueva la próxima vez que se abre.

## Notas
- Las sesiones se guardan con ☰ → COMPARTIR / GUARDAR .JSON (el guardado directo en Drive solo funciona dentro de claude.ai).
